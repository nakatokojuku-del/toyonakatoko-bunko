# 二人目の独立翻刻 page_15〜page_29（README）

『倭姫命世記』書写本（寛文九年 出口延佳校合本）の page_15〜page_29 を、既存の翻刻（`zenbun/` ほか）を見ずに画像だけから独立に翻刻したもの。突き合わせ（ダブル入力）用。

## 方針
- 本文の字のみを翻刻し、片仮名の傍訓・送り仮名・返り点は採らなかった。宣命書きの小字（支・止・天・弖・仁・尓・波など）は本文に入れた。
- 本文の左右に添えられた小字の書入れ（「〜イ」の異本注記、補入字など）は本文に入れず、各丁の「注」に記した。ただし行中で本文と区別しにくい小字は本文に入れ、注でその旨を書いた。
- 字体は原本の字面を優先した（例：叓、覔、宍〔完の形〕、户、廿〔卄の形〕、国／國の書き分け）。
- 割注は `〔注：右行／左行〕` の形で、二行割の右行・左行を「／」で区切った（page_23 は「／」を省いた箇所あり、注を参照）。
- 頭注（すべて朱）は `【頭注〈朱〉…】` として、頭注がかかる行の前に置いた。行頭の朱の圏点は `〈朱〉○〈/朱〉` とした。

## 主な判読の難所
- **字形の紛らわしい組**：「波／彼」（氵と彳の区別がつかない。page_15・17・20・25）、「日／月」（page_20 R1、page_22 R5）、「相／桐」（page_15）、「乗／柔・来」（page_17・21・23）、「美／羑・義」（page_16 以降の「美」はすべて羊＋久の形）、「嶋／鳴・鳩」（鳥偏に近く書かれる）。どれも文脈と傍訓から判断したので、突き合わせで食い違いが出やすい。
- **虫損**：各丁の上部と中ほどに虫食いの筋があり、page_15（R4末・R6末・L7）、page_16（R6「久求都彦」）、page_18（R4末・L2）、page_21（L3末・L4）などで字が欠ける。
- **割注の読み順**：page_23 R6〜R7 の二行割（白銅鏡二面の注）は行をまたいで続き、配置と読み順に自信がない。page_19 R8・page_21 R1・page_28 L1 の割注は比較的明瞭。
- **重複書写**：page_17 R9 は左丁1行目と同文（「于時倭姫命御水飲止詔久尓老尓何處」）が丁の終わりに重ねて書かれている。
- **異本注記・補入**：「〜イ」の小字書入れが多く（page_16・17・18・22・25・26・28）、本文との区別に迷う箇所がある。page_18 R8 の「恐［志？］詔」の補入「止」も同様。
- **通行本と字面が違うと思われる箇所**（注に記録）：page_15「挟」（狭）、page_23「律見」（津見）、page_26「竹建」（竹連）、page_27「秦」（膚）、page_17「取鷲老」の語順、page_20「留」「今歳」、page_26「伊鈴」（五十鈴）など。
- **頭注（朱）**：page_16・18・19・20・23・27・28・29 にある。page_20 は『日本書紀』引用の八行。page_19・28 の頭注は首字が欠けるか崩れていて判読不確実。

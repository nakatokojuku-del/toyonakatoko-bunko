# 倭姫命世記 二人目の独立翻刻（page_00〜page_14）

先行の翻刻を見ずに、画像だけから独立に読み起こしたもの（ダブル入力の二本目）。突き合わせのときは、食い違った字を画像で確かめてください。

## 翻刻の方針
- 本文の漢字だけを採り、墨の片仮名振仮名・送仮名・返点・朱引・合点は省いた。行間の小字のうち、本文の続きとみられる字（止・志・支・登・比・弖など）は本文に入れた。
- 朱の傍注（神名の比定など）は、注が付く語の直後に〈朱〉…〈/朱〉で入れた。
- 割注は二行割りを右行・左行の順に続けて〔注：…〕に入れた。
- 頭注は、上端が切れて一字目が見えないものが多い。見えない字は［？］または［某？］にした。
- 行番号は丁ごとに右から数えた。

## 全体に関わる判読
- **「弖」**：「ヨ」の下に「工」を書いたような、「互」「亙」に似た字が多く出てくる。page_00〜06 を読んでいる間は［亦？］としていたが、page_07 の「領賜利弖」「無黒心志弖」で、送り仮名「て」に当たる万葉仮名「弖」と判断し、前の丁も「弖」に改めた（「給弖」「依弖」「賜弖」「宣弖」など）。先行翻刻と食い違う場合は、まずこの字を確かめてください。なお page_07 R7「亦詔日」の「亦」は普通の「亦」の字形で、区別した。
- **「美」**：page_00 L8「神漏美」、page_07 L2「齋愼美」の「美」は、下部が「義」に似た崩しになっている。
- **「卅」「卌」「廿」**：年数の字は形が似ていて紛らわしい。振仮名が読めるところは振仮名で決めた（page_03 L1「卌二年」、page_05 L4「卅九年」など）。

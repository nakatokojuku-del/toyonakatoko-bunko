# 倭姫命世記 独立翻刻B（page_30〜44）

`倭姫命世記/images/page_30.jpg`〜`page_44.jpg` を、既存の翻刻（`zenbun/`、`index.html` の本文、校正メモ等）を見ずに、画像だけから翻刻したもの。突き合わせ（ダブル入力）用。

## 作業方法
- 各画像（2000×1500）を PIL で右丁・左丁に分け、さらに半丁を二つの縦帯に切り出して読んだ。難しい箇所は行ごとに2〜3倍に拡大し、朱の淡い箇所はコントラストを上げて確かめた。切り出し画像はコミットしていない。
- 通行本の知識は判読の手がかりにだけ使い、本文には原本の字面を書いた。通行本と違う字や字形の問題は、各丁の「注」に書いた。

## 表記で決めたこと（突き合わせのときの注意）
- **墨の訓点・振仮名・送り仮名は採っていない。** 本文行の右傍・左傍にある片仮名、返り点などはすべて省いた。
- **宣命書きの小字**（久・波・毛・乃・止・支・天・尒・利・倍 など）は本文の中にそのまま入れ、`〔注：〕` にはしていない。
- 割注は `〔注：右行／左行〕` の順に書いた。割注が次の行に続く場合は、次の行も `〔注：…〕` だけの行にした（page_36〜38 に多い）。
- 行間の朱書・墨書は、番号を付けずに `（行間朱書）〈朱〉…〈/朱〉` の形で、その位置の前後の行の間に入れた。
- 本文の字の傍らにある朱の傍書（例：「豊受宮」「清寧天皇」）は、その語の直後に `〈朱〉…〈/朱〉` として入れた。
- 異本注記の「…イ」（例：「高イ」「写イ」）は `〔注：…イ〕` として該当字の直後に入れた。
- 淡い朱の文字影の多くは、向かいの丁や前後の丁からの裏写りとみて採らず、注にだけ書いた。
- 「门」（門）、「国」（國）、「写」（寫）、「礼」（禮）、「点」（點）など、略体で書かれている字は略体のまま書いた。
- この筆者の「焉」は「尋」に近い字形で書かれる（page_32・33・35・40・41・42）。「焉」と判読した。
- この筆者の宣命書きの小字「天」は「立」に近い字形で書かれる。「天」と判読した。
- この筆者の「左」は「大」や「九」に近い字形で、「右」は「石」に近い字形で書かれる（page_35・36・38）。

## 全体を通じての注意
- page_36〜38 は神名・宮名の列記で、割注が行をまたいで続く。右行・左行の読み順は配置どおりに書いたので、もう一方の翻刻と行の切り方が違う可能性が高い。食い違ったときは、字そのものより先に、割注の区切り方を確かめてほしい。
- 朱の頭注・行間注は、どの行の上（間）に置くかに判断が入っている。位置のずれは字の違いではない。
- 各丁の末尾に「見直し済み」と書いた。いずれも画像と読み合わせて見直した。

## 3. 既存の章見出し・要約・解題と食い違う点

1. **page_30 に「心御柱」の記事はない。** 本丁は外宮（豊受大神）の鎮座段で、朱書は R5 頭注の「豐受宮」だけである。「心御柱」「鏡・大刀・小刀・矛・楯」「御船・五十鈴河」は本丁にない。校正メモ表C-C13・C16・C17 の指摘を画像で確かめた。章題「★ 心御柱・伊勢神宮鎮座」と、解題・README の「心御柱＝page_30」は見直しが必要。
2. **page_30 の現行翻刻（大成と校合済みとされる部分）は、画像と大きく食い違う。** 「〈朱〉皇太神吾一所耳」は墨書、「食邦波國與依」は「食丹波國與佐」、「底津磐根」は「下都磐根」。全文は `page_30.md` を見てください。
3. **倭姫命の薨去は page_33・page_34 にある。** page_33 R1「（尾）上山峯石隠坐」と朱頭注「倭姫命薨去」、page_34 L1「（大泊瀬）稚武天皇御宇自退薨」。既存要約の第六巻「倭姫命崩御」の位置と照らし合わせてください。
4. **年紀**：page_41 R7 は「垂仁天皇廿二年」で、既存要約の「垂仁28年」ではない（表A-74 と一致）。page_33 L3 の遷幸は「丁巳年冬十月甲子」、page_41 L1 は「廿六年冬十月」。
5. **page_31 は外宮の御饌・物忌・摂社の記事**で、既存翻刻の「度會郡建神社（神服織社・神服社）の創建」とは無関係。神服織社の記事は page_33 L1–L2 と page_41 にある（表B-6）。
6. **page_36・37**：既存翻刻の「荒祭宮一座 皇太神荒魂神（神異形也）」の「神異形也」はない（表B-7）。「諸国祭支夫八十社座中」はなく、「四至神四十四前宮中祭之」は page_37 L6 にある（表B-8）。
7. **page_38 の酒殿神**：割注は「豐宇賀能賣命…天女善為醸酒一坏吉万病除之形石座也」で、「御酒奉所」の語はない（表B-9）。
8. **page_39 は一行も翻刻されていなかった丁**で、大國玉比賣神に付けた注（記紀の引用、延佳の按語、伊勢国風土記逸文「裏書勘注」）である。本書に風土記逸文の引用があることは、解題で触れてよい点。
9. **奥書（page_42〜44）**：校正メモ表C-C22〜C38 の読みをすべて画像で確かめ、一致した。とくに次の点。
   - 撰者の記事「于時大神主飛鳥孫御氣書之」「祢宜五月麻呂撰集之」が現行サイトにない。
   - 署名は「雅晴」「章尚」で、「延晴」ではない。書写は「丁卯歳五月」「應永廿五年戊戌仲夏端午後一日」。

   - 延佳の跋は「正誤字・入闕字・補落行・加点」の四事で、末尾は「延佳謹識」（解題表の「校合云正誤字八個字」は誤り）。
   - 丁卯歳の右上に小字「喜慶［元？］」がある。嘉慶元年（1387）丁卯の書写を示すと見られ、解題の書写の系譜に加えられる可能性がある。
10. **延佳の校合の跡**：page_36 R2 の補入注、page_34 の「異本」傍記、page_39 R4 の「延佳按古事記」など、寛文九年校合本としての延佳の書入れが本文中に複数ある。解題で校合本の性格を述べる材料になる。

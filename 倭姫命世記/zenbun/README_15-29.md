## 3. 既存の章見出し・要約・解題と食い違う点

### 第四巻「遊行後期（尾張〜伊勢・15〜19頁）」

- 見出しの「尾張〜伊勢」：page_15〜19 はすべて伊勢国内（瀧原・度会・二見・五十鈴川方面）の記事で、尾張は出てこない。
- 要約「度會国造の名と神戸進納」「御鈴神戸を定めながら」：該当する本文はない。page_15 は速河彦・高水神による神田の献上（狭田国・坂手国）と御船神社。「鈴」は「船（舩）」の誤読（校正メモ表A-23）。
- 要約にない主な記事：瀧原宮（page_16 朱）、大若子命の五十鈴河上の奏上（p17）、二見浜（p17）、堅塩と堅多社・佐見社（p18）、宇遅都日女（p18）、抜穂田（p19）、太田命（p19）。
- p19 の朱書「雲来社」に当たる字はない。朱書は「抜穂神田」「朝熊社」「土公氏社（祖也）」「翁事」。

### 第五巻「五十鈴川到着・伊勢鎮座（20〜24頁）」

- 要約「垂仁76年」は **廿六年**（p20 L2）。
- 要約「伊雜宮が初出」：p20〜23 に伊雜宮は出ない。「伊雜」の初出は p24 L3「伊雜方上」、伊雜宮は p25。
- 要約「垂仁27年丙寅に伊勢国の鎮座が確定」：p24 の廿七年は **戊午**で、真名鶴の記事の年。鎮座は廿六年（p20〜21）。
- **心御柱**：p21 R1 の割注に「一名天御柱／一名心御柱」と墨書で明記される。CAPTIONS の「30: ★ 心御柱 伊勢神宮鎮座」、章見出し「★ 心御柱・伊勢神宮鎮座（30頁）」、page_30 を心御柱の章とする解題は、page_21 に改める必要がある（校正メモの最重要の指摘を、全文翻刻でも確かめた）。
- 第五巻の範囲には、ほかに次の記事がある：御裳須曽河の起源（p21）、国讃め「神風伊勢国」（p22）、祭官・神国造兼大神主と齋宮（p22）、八尋機屋と神衣（宇治機殿・磯宮、p23）、朝熊の神宝二面（p23）、嶋国国崎の御贄（p23）。

### ★ 伊雜宮創建・真名鶴・大歳神（25頁）

- 章見出しは「25頁」だが、真名鶴の発見（廿七年戊午秋九月、伊雜方上の稲を白真名鶴が咋えて鳴く）は **p24 左丁**から始まる。p25 は懸税・御神酒の起源と伊雜宮の造営、翌年秋の二度目の真名鶴。章の範囲は p24 L〜p26 R とするのが本文に合う。
- 要約「伊佐波登美神に命じて伊雜宮（朝熊山嶺社）を造らせます」：書写本では、伊佐波登美神が造るのは**伊雜宮**（p25 R5–R6）。**小朝熊山嶺社**は、朝熊河後の葦原の石に坐す神（大歳神）のために造る別の社（p25 L1–L2）。伊雜宮＝朝熊山嶺社とする括弧は本文に合わない。
- 要約・解題「眞名鶴は大歳神として祀られ」：書写本の字は「彼鶴**真鳥**乎号稱大歳神」（p25 R7）。
- 翻刻欄の読み下し（大成による）と書写本の字面の違いは page_25.md の注に一覧した（校正メモ表C-1〜C-7 と同じ結果。ただし表C-1 の「為支」「令抜支」は、本報告では「為弖」「令抜弖」と読む）。
- README の「伊雜宮造営者 伊佐波登美神」は画像と一致する。

### 第六巻「伊雜宮続編・御杖代継承（26〜29頁）」

- 要約「伊雜宮の御田・神社・神戸の制定が続きます」：p26 は懸税（細税・大税・千税八百税余）と八握穂社、斎宮の忌詞。p27 は大祓の詞章と年中の祭り。伊雜宮の御田・神戸の制定の記事はない。
- 要約「御杖代制度が代々継承され」：該当する本文はない。p28 は倭姫命が老齢を理由に五百野皇女（久須姫命）を御杖代として遣わす記事のみ。
- 要約「倭姫命崩御」：p28 は**退任**（「年既老耆不能仕吾足止宣天」）。崩御（薨去）は p33 以降（校正メモ表B-13）。

- 日本武尊の東征の年は書写本では **景行廿八年戊戌**（p29 R3）。

### 解題

- 「御饌・懸税・神嘗祭の起源を語る」：懸税の起源は p25（伊佐波登美神の抜穂を皇太神の御前に懸ける）と p26（細税・大税）の両方に書かれている。解題の「伊雜宮創建の章（25頁）」に懸税をまとめているのは、p26 も含めると本文に合う。

## 注
- 本丁は別宮の神名と御形（御神体）を列記する段で、宮名・神名は大字、説明は細字の割注。割注は右の列から順に「／」で区切った。各項の頭に朱点（段落の印）がある。
- 行の切れ目：A は割注の続きの列（右丁 R2、左丁 L5）を独立した行として数えず、右丁を 7 行、左丁を 5 行とした。画像では、荒祭宮の割注は二列を使い切って次の列（R2）に続き、並宮の割注も次の列（L5）に続く。B と同じく列ごとに行番号を付けた（右丁 8 行、左丁 6 行）。そのため A とは行番号が一つ二つずれる。
- 左丁の短い列：L2「魚見神／社也」（L1 と L3 の間の上部の小字二列）は独立の列として L2 とした（A・B 同じ）。瀧原宮の割注のあとの「是也」（L3 と L4 の間の上部に「也是」と書き返り点で「是也」）と、伊雜宮の割注末の「坐」（L6 の左上）は、B は別行（L4・L8）とするが、どちらも割注の一、二字のはみ出しなので A に従って割注の第三列として入れた。
- R1・R2 割注：「八十枉津日」（R1 左列末）と「神也」（R2 右列頭）は朱の囲み線で囲まれている。既存翻刻の「神異形也」に当たる字はない。R2「瀬」に墨線がかかり、右に小字「新」形がある。
- R2 の延佳注：R2 と R3 の行間、上部に墨の細字「延佳按伊以下七字可有之仍補入」（延佳按ずるに、伊以下七字之れ有るべし、仍て補入す）。A は R2 本文、B は R3 の前の行間注とする。四字目は亻に尹の「伊」の形。ただし朱で囲まれた「八十枉津日神也」がちょうど七字で、「伊弉那伎太神所生」は八字なので、補入されたのは囲みの七字で、「伊」は「八」の誤写の可能性がある（B の指摘）／確信度 低。出口延佳の校合が本文に見える例。
- R3「伊佐奈岐社二座」：「社」は示偏（通行本「伊佐奈岐宮」）。
- R4・R5「〔注：左方〕〔注：右方〕」：小字二字の割書（右に「左」「右」、左に「方」）。
- R4 末の朱書：R4 と R5 の行間の朱の細字。A は R3 末、B は R5 の前の行間注とする。「入於宮社」は「入」の下に「於」と「宮」の二字が見える（宮は「官」とも読める。続日本紀は「入官社」）。「國」の下の三字は崩しが強く、B の推定「伊［弉？］［奈？］［岐？］」に従った（A は四字とも［？］）。「改社」の「社」の右傍に朱の小字「称」。B の「爲宮」の「爲」に当たる字は見えず、A に従い「改社〔注：称〕宮」とした。末字「食」は A・B とも／確信度 低。
- R5 末の朱書：R5 と R6 の行間。A は R4 末、B は R6 の前の行間注とする。「以東［季？］月讀命」の［季？］は「李」「爲」にも見える／確信度 低。
- R6「形馬乗男形也」：一行の小字。
- L1「［敍？］鏡座」：A［？］ B［靈？］。画像は余に攴（又）の「敍」に近い字形で、ほかの項の「靈御形鏡座」の「靈」の崩しとは形が違う。page_37 R1・L8 の「形」（开に欠状）とも違うが、文脈は「形鏡座」（伊雜宮の割注「形鏡坐」と同じ型）が自然なので「形」の可能性もある／確信度 低。
- L1 割注「飛鳥宮御宇丙寅／年九月十一日遷」：「丙寅」は A寅 B辰、画像は右傍の訓「ヒノヘトラ」（丙寅）がある／確信度 高。左列は A「年十一月十一日遷」 B「年九月十一日遷」、画像は「年」の下がナに乚の「九」一字で、その下に「月」。左列は七字／確信度 中。
- L1 朱書「當時現在乗馬男形也」：L1 と L2 の行間。A は L1 末の注、B は L3 の前の行間注。L1 の左にあるので L1 末に付けた。
- L2「魚見神／社也」：A は本文、B は〔注：〕。L1 と L3 の間の上部の小字二列なので〔注：〕とした（表記の違い）。
- L3「是也」：A は割注の第三列、B は別行の L4。上の「行の切れ目」の項を参照。
- L4・L5 割注：「此二神因河海持別而生神八柱」。A・B 一致。
- L6 割注：「天牟羅雲命裔天日別命子玉柱屋姫命是也形鏡坐」。「牟」と「子」に墨線がかかる。左列頭の「玉」は点のない「王」の形。

## この丁の内容
皇太神の別宮の神名と御形：荒祭宮（荒魂・八十枉津日神／瀬織津比咩神、御形鏡）、伊佐奈岐社二座（伊弉諾尊・伊弉冊尊）、月夜見命（御形は乗馬の男形）とその荒魂、魚見神社、瀧原宮・並宮（速秋津日子神・速秋津比賣神）、伊雜宮（玉柱屋姫命）。延佳の補入注と、宝亀・貞観の官社・宮号に関する朱注を含む。

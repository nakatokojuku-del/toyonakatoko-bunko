# 倭姫命世記 書写本 page_30〜44 突き合わせ報告

二つの独立した全文翻刻（翻刻A：`yamatohime-zenbun-30-44` の `倭姫命世記/zenbun/`、翻刻B：`zenbun-b-30-44` の `倭姫命世記/zenbun_b/`）を丁ごとに突き合わせ、食い違う字を画像（`倭姫命世記/images/page_NN.jpg`）で確かめて、確定翻刻 `倭姫命世記/kakutei/page_NN.md` を作った。

## 方法

- 比較は Python の difflib で行った。各丁の本文・割注・頭注から表記記号（〈朱〉〔注：〕【頭注】［？］など）を除いて字の並びを作り、A と B を突き合わせた。行の切れ目が A・B で違う丁（page_36〜38・41・42）があるので、一致率は行単位ではなく丁全体の字の並びで出した。
- 字体だけの違い（豐／豊、從／従、爲／為、尓／尒、門／门など）は対応表で同一視して数えた。件数は機械的に数えたもので目安である。確定翻刻では画像の字形に近い方を採った。
- 表記の付け方の違い（頭注・行間注・傍書の置き方、割注を一行とするか二行とするか、朱書を本文に入れるか〔注：〕に入れるか）は、既存の規則（朱書 `〈朱〉…〈/朱〉`、割注・細字・傍書 `〔注：…〕`、頭注は行の前に `【頭注〈朱〉…】`、読めない字 `［？］`、候補がある字 `［某？］`）にそろえ、各丁の注に記した。行間・行の左右に書かれた傍書は、その行の末（または注記する字の直後）に `〔注：…〕` で置いた。本行の位置に書かれた朱書は本文中の `〈朱〉…〈/朱〉` とした。
- 読みが違う箇所は、すべて画像をその箇所だけ切り出し、3〜5 倍に拡大して確かめた。判定には確信度（高・中・低）を付けた。
- この本では、漢字の傍記・異本注記（「某イ」）は注記する字の左傍に、片仮名の訓は右傍に置かれるのが通例である（page_30 R2「須イ」・R3「治イ」など）。所属の判断に迷う傍記はこの通例に従った。
- 小字二行の割書（「倍利」「乎波」「志天」「万天」など）は、右行から左行の順に本文に入れた。翻刻A は左行の字を落としたり〔注：〕に回したりしている箇所が多く、A の「〔注：信〕」はいずれも「倍」の読み誤りだった。

# 倭姫命世記 突き合わせ報告（page_00〜page_14）

翻刻A（`transcribe/yamatohime-zenbun-00-14` の `倭姫命世記/zenbun/`）と翻刻B（`zenbun-b-00-14` の `倭姫命世記/zenbun_b/`）を丁ごとに突き合わせ、食い違う字を画像で確かめて、確定翻刻 `倭姫命世記/kakutei/page_00.md`〜`page_14.md` を作った。

## 方法

- 本文の行（右丁・左丁）を行番号ごとに取り出し、Python の difflib で A と B を字単位に比べた。一致した字はそのまま採った。
- 食い違いは三つに分けた。
  - **字体の違いだけのもの**（豐/豊、穗/穂、舍/舎、并/竝/並 など）：画像の字形に近い方にそろえた。画像で確かめたもの：「豊」（曲に豆の略体）、「穗」（禾に惠）、「霊」（下が业の略体）、「関」（門構えの中が关）、「礭」「戾」「舍」「床」、「並」（丷に业。A の「并」、B の「竝」のどちらでもない字形）、L 割注などの「国」（略字体）。一字ずつは確かめにくい残り（參・隨・愼・隱・繼・狹・惠 など）は、A の方針どおり旧字にそろえた。
  - **表記の付け方の違い**：既存の表記ルール（朱書 `〈朱〉…〈/朱〉`、割注・細字 `〔注：…〕`、頭注は行の前に `【頭注〈朱〉…】`、読めない字 `［？］`、候補がある字 `［某？］`）と、翻刻A の README の方針にそろえた。主なもの：二つに分かれた朱の頭注は A にならい全角空白で区切って一つにまとめる、小字二字の左右並び書きは右から読んで本文に入れる、「介」に似た「尒」の字形は「尓」と書く、墨の異本注記（「〜イ」）や傍記は本文に入れず注に記す、page_02 の朱の枠囲みは `〔朱枠：…〕`。
  - **読みが違うもの**（別の字、字の有無、頭注の位置など）：その箇所を画像から切り出し、3〜4倍（一部は5〜6倍）に拡大して確かめ、確信度を付けた。頭注がどの行の上にあるかの食い違いも、画像で位置を確かめたうえで、この表に入れた。
- どちらにも［？］・［某？］がある字は画像を見直し、読めたものは埋めた（page_02 R2 朱傍書の［？］など）。
- 書写本の字面を書くことを原則とし、通行本の知識は判読の手がかりにとどめた（例：page_12 L6 は通行本・頭注の「真久佐牟氣草」ではなく、画像どおり「眞木佐年毛久佐向國」とした）。
- 各丁の注には、A と B が食い違って判定した箇所を「A… B…、画像は…」の形で残した。

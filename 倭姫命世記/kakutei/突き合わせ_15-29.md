## 1. やり方

1. A・B の本文（頭注・割注を含む）を丁ごと・行ごとに difflib で突き合わせ、食い違いを書き出した。
2. 食い違いを「字体の違いだけのもの」「表記の付け方の違い」「読みが違うもの」に分けた。
3. 読みが違うものは、すべて画像の該当箇所を切り出し、3倍に拡大して判定した。行の位置は画像の縦方向の墨の濃さの分布から求め、字の位置は行の字数から割り出した。
4. 字体の違いは、書写本の字形に近い方にそろえた。表記の付け方は、朱書 `〈朱〉…〈/朱〉`、割注 `〔注：右行／左行〕`、頭注 `【頭注〈朱〉…〈/朱〉】`（かかる行の前）、読めない字 `［？］`、候補つき `［某？］` にそろえた。
5. 一致した字はそのまま採った。各丁の注に、A・B が食い違って判定した箇所を「A○ B○」の形で残した。

### 判定の中で立てた二つの見方

- **「ヱ」形の小字は「弖」**：A・B とも「ヱ」形の小字を「弖」と読む方針だが、A は同じ字形を「止」と書いた箇所が多かった（p20・22・24・26・27 など）。画像で「ヱ」形を確かめた箇所は、すべて「弖」とした（確信度 高）。「ヱ」形が「支」の別体である可能性は、A の README のとおり塾主の確認を要する。
- **左右に並ぶ小字は右→左に読む**：宣命書きの小字が二字、行の中で左右に並べて書かれる箇所がある（p20 に特に多い）。右の字から読むと、「間仁毛（あひだにも）」「如日月奈利（なり）」「念比弖（おもひて）」「茂礼利（しげれり）」「宣良波（のらば）」「神祀古止（こと）」のように文意が通る。A・B の食い違いの多くは、この並びの読み方（片方を傍書とみるか、左から読むか）の違いだったので、右→左で本文に採った。ただし p21 R7・p29 R2 の「利／信」、p23 L7「止／支」、p21 R6「天／仁／志」、p20 R7「志比」は、この読み方では文意が通りにくく、例外として扱った（各丁の注を参照）。
